## 🚀 Featured — Zuro CLI

> **The tool I wish existed when I started backend development.**

Stop copy-pasting the same Express + TypeScript boilerplate for every project.

```bash
# One command. Production-ready backend. 60 seconds.
npx zuro-cli init my-app

# Then add only what you need
npx zuro-cli add auth
npx zuro-cli add database
npx zuro-cli add validator
```

**What you get instantly:** Express · TypeScript · Helmet · CORS · Pino Logger · .env validation
