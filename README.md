## Selected work

**[Script Judge](https://github.com/BriyanPatel/script-judge)** · TypeScript · Next.js · Postgres

Paste a video script, get an editorial verdict. It runs the script through a
judgment model against 34 short-form or 27 long-form checks — opening, progress,
clarity, promise, ending — and returns approve / revise / reject with the exact
passage, the reason, a repair action and a resolution test for each priority
issue. Everything countable is computed in code rather than asked of the model,
answers are validated before they can score, and every judgment is stored with
its rules version so thresholds can be recalibrated against real retention.

`engine` · rules, states, diagnostics &nbsp;|&nbsp; `eval` · live model evaluations with a go/no-go gate &nbsp;|&nbsp; 137 tests
